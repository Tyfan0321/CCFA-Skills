# ICLR Venue Guide

Resolve the year and submission stage from the request or existing project before selecting rules or templates.

- **ICLR 2027 conference:** read [iclr2027.md](iclr2027.md). It covers the official template, anonymous submission, page accounting, AI disclosure, and submission checks.
- **Another year or track:** verify that edition's official author guide and template. Historical styles in `ccf-latex-templates/ICLR/` are not current-policy references. Do not rename an older style file to simulate a new edition.
- **Year unspecified:** use the existing project target. If none exists, ask for the year before a final compliance decision; continue year-independent writing or evidence review meanwhile.

Preserve the user's established source layout and build command. `ccf-paper-writer` owns prose, `ccf-project-scaffolder` owns requested template setup, and `ccf-submission-checker` owns submission readiness. This guide does not authorize uploading a manuscript.
