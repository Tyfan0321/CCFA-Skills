# ICLR 2027 official template assets

Source: [ICLR 2027 style archive](https://media.iclr.cc/Conferences/ICLR2027/iclr-2027-style-files.zip), linked by the [author guidelines](https://iclr.cc/Conferences/2027/AuthorGuidelines).

Downloaded and verified on 2026-09-12. The seven `.tex`, `.sty`, `.bst`, and `.bib` files in this directory are unmodified archive contents. Copy them together to a working directory before building; do not write build products into the installed skill.

- Entry: `iclr2027_conference.tex`, the official formatting example.
- Style and bibliography: `iclr2027_conference.sty`, `iclr2027_conference.bst`.
- Supporting files: `math_commands.tex`, `natbib.sty`, `fancyhdr.sty`, and the example `.bib`.

The example's author names, citations, statements, and formatting prose are not the user's manuscript. For research work, preserve the project's own bibliography and draft statements from actual author information. Follow [the ICLR 2027 guide](../../../ccf-paper-writer/references/venue-guides/iclr2027.md) using the correct sibling installation layout.
